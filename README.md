## 🌟 Key Highlights

- **Aesthetic**: Modern dark SaaS theme (`#0B1120`), glowing electric blue (`#3B82F6`) and cyan (`#06B6D4`) accents, and glassmorphic elevated cards (`#111827`).
- **Flagship UX Case Study**: **Arrear Clearing** — A student academic success mobile app designed to help college students strategically organize, study, and clear backlog examinations.
- **Interactive Design System Showcase**: Click-to-copy color palette tokens with instant toast notifications, live interactive button states, and typography scale inspector.
- **ATS Resume Viewer**: One-click ATS-compliant interactive resume modal with a built-in `Print / Save PDF` action.
- **5-Stage UX Process**: Empathize & Research → Define & Architect → Ideate & Wireframe → Design & Prototype → Test & Refine.
- **Recruiter Contact**: Interactive contact form with live validation, direct email (`praveenkumar880761@gmail.com`), and phone/WhatsApp (`+91 9363256311`).

## 🚀 Getting Started

Simply clone the repository and open `index.html` in your web browser:

```bash
git clone https://github.com/p7552205-ship-it/portfolio.git
cd portfolio
```

Double click `index.html` or serve with any static web server:

```bash
# Python 3
python -m http.server 3000

# or with VS Code Live Server extension
```
